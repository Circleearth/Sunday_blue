## 2026-11-10 — Codex：专注升级番茄钟 + 完整页面与结束提示音

用户在 Claude 页面收尾后明确授权：全面优化专注界面、代码改为番茄钟、结束提醒可自选 MP3。本轮授权取代此前 UI-only 边界，**仅本轮新增番茄钟所需服务有变动**；未扩展其他模块。Claude 上一批交接已读、相关页面测试和全量基线通过，原记录原文归档至 `archive/2026-11-10_claude-by-codex.md`。

### 完成内容与文件

- `module_views/focus.py`：圆环倒计时、三阶段切换、任务/陪伴侧栏、今日汇总、有效记录、非阻塞到点结算提示；窄窗口上下排布。复用现有主题 tokens 和 UI 字体；无新框架或大依赖。保留 Claude 的持久活动字段回填、idle 草稿与历史起止时间。
- `modules/focus.py`：默认 25/5/15 分钟，每 4 个完整番茄建议长休息；时长/间隔可改。到点自动结算，下一阶段手动开始。时间截断到目标，重复 tick/finish 不重复发币；休息不写活动、不发金币、不触发完成活动事件。提前结束仍按实际有效专注结算，但不算完整番茄。原 >120 秒、日金币上限和暂停/休眠保护保留。
- `modules/hub.py`：独立一秒 focus_timer，切页/最小化继续检查；focus_completed 发页面通知、声音与任务栏/可用托盘提醒。完全退出不计时，重启暂停；不会回放旧声音。
- `modules/focus_preferences.py`：配置校验/导入音频；`module_views/focus_settings.py`：时长、间隔、三阶段独立音频、总音量/开关、试听/停止、恢复默认。保存前是草稿；时长仅下一轮生效。取消选择不会改当前设置；已导入但未保存的文件可能保留，暂不自动清理避免误删共享音频。
- `modules/focus_alarm.py`：QtMultimedia 懒加载；默认本地生成柔和 WAV，MP3/WAV 拷贝进软件目录，20 MB 上限，最多一次播放 30 秒。故障尝试系统提示音并展示错误，绝不撤销结算。停止/关闭释放 Windows 文件句柄。
- `tests/test_pomodoro.py`：7 项新测试；README、架构和模块索引已同步。

### 存储、兼容和维护限制

`data/modules.sqlite3` 只新增 `focus_timers(run_id,phase,duration,long_every,end_reason)` 附属表；旧表/真实数据不迁移不重写。旧活动没有 timer 元数据，按旧正计时恢复，手动结束即可。阶段结束标记与活动/金币结算在同一事务；声音是事务后的最佳努力提醒，不能声称崩溃时一定会响。

配置在 `module_settings` 的 `pomodoro_options`；音频在 `data/sounds/focus/`，自选文件以内容哈希命名。多人格仍共用一个当前计时，不为每角色复制计时器。后续不得在 UI 内新增发币/计时状态机，不得让休息计入专注事实，不能为了方便恢复就奖励关机时间。新页面无远端请求。

回滚前先结束当前阶段，**尤其是休息**；旧代码不认识休息元数据，不能让旧代码接管未结束的休息。回滚代码即可，保留数据库和音频。无打包、无真实数据删除、未修改 QQ / 角色删除 / 人格或记忆权限。
