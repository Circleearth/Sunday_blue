# Sunday_Blue 美术方向

正式资产在用户确认后生成并接入。当前样图仅作风格参考。

| 主风格 | 使用位置 | 构图与材质 |
| --- | --- | --- |
| 日常手绘 | 生活、陪伴、结算 | 奶油色、低对比、舒展的笔触与留白，角色比例自然。文字区域留出平静底色。 |
| 海边书房写实 | 桌面与日常背景 | 固定窗景、海面、随风轻动的薄帘与绿植。日间自然光，下午夕阳，夜晚星空。切换时维持机位与家具位置。 |
| 原创卡通页游 | 雾铃谷场景 | 固定俯视角、清晰大色块。田垄与水渠、铁砧与水车、洞口与路标分别形成可辨认的区域。细节集中在交互点附近。 |
| Q 版角色 | 村庄、牧场 | 独立透明精灵，约三头身，轮廓与职业道具清楚。场景底图中留出站位。 |
| 视觉小说立绘 | 游戏对话 | 与 Q 版共用发型、眼睛、服装和标志物，使用自然比例的大立绘与底部对话框。表情和口型可独立扩展。 |
