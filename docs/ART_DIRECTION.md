# Sunday_Blue 美术方向

雾铃谷内置素材与日常桌面素材分别维护。已接入的游戏图片、文件规格和替换方式见 [雾铃谷指南](HAMLET.md)。

| 主风格 | 使用位置 | 构图与材质 |
| --- | --- | --- |
| 日常手绘 | 生活、陪伴、结算 | 奶油色、低对比、舒展的笔触与留白，角色比例自然。文字区域留出平静底色。 |
| 海边书房写实 | 桌面与日常背景 | 固定窗景、海面、随风轻动的薄帘与绿植。日间自然光，下午夕阳，夜晚星空。切换时维持机位与家具位置。 |
| 日系轻像素 | 雾铃谷场景 | 深色偏粗轮廓、干净色块与受控的细节。地标在谷地图上有固定位置。农田近景保留中央空地，由程序绘制可点击地块和作物。 |
| Q 版精灵 | 地图、牧场、战斗 | 独立透明精灵，约三头身，轮廓与职业道具清楚。战斗图集脚底对齐，场景底图留站位。 |
| 非 Q 版轻像素立绘 | 游戏对话 | 发型、服装和标志物与角色设定一致。保留可见像素边缘、柔和分层光影与自然成人比例。优先核对头颈到肩的衔接、肘腕方向、持物重心、手指结构及袖口遮挡。透明底与独立对话区域。 |

办公模式统一管理生活侧装饰图。游戏在独立窗口维护自己的资源与交互。
