# Sunday Blue UI 设计系统

本文件是界面视觉规则的单一入口。新增模块先复用这里的变量和组件状态，不在业务页面散写颜色、字体和间距。

## 设计方向

界面以安静、轻量、可长期阅读为主。聊天内容是视觉中心，角色素材保留个性；装饰不与正文争夺注意力。深色与浅色使用相同的语义变量，不分别维护两套组件规则。

## 代码入口

- `sunday_blue/design_system.py`：颜色、间距、圆角、精选字体和九角色推荐字体。
- `sunday_blue/theme.py`：将语义变量生成 Qt stylesheet。
- `sunday_blue/ui_components.py`：气泡、输入框、立绘等自定义组件，从设计变量取色。
- `sunday_blue/chat_preferences.py`：界面字体、角色气泡字体和分段设置。

## 变量规则

颜色只按用途命名：`canvas`、`surface`、`text`、`text_muted`、`border`、`accent`、`danger`、`user_bubble`、`assistant_bubble`。新增颜色前先判断现有语义是否足够。

间距使用 4、8、12、16、24、32 像素序列。普通控件圆角 7，面板和气泡圆角 10。常规按钮和输入控件保持同一视觉高度；紧凑工具按钮可例外。

界面字号固定由设计系统管理，用户只选择界面字体。气泡字号、字重和字体按角色配置。导入字体只进入当前角色，不改变其他角色或 UI。

## 字体策略

UI 只展示四个适合长时间阅读的中文字体：思源黑体、微软雅黑 UI、等线、幼圆。气泡增加思源宋体、楷体、仿宋和华文字体。列表文案标出字体气质，不展示系统内数百种无关字体。

九角色首次使用各自推荐字体；用户设置保存在 `chat_display.role_fonts.<role>`。自定义字体文件复制到 `assets/fonts`，配置只保存相对路径。目标机器缺字时 Qt 回退到可用中文字体，用户可重新导入。

## 组件约束

- 气泡四边使用相同内边距，短文本随内容收窄，最大宽度保持聊天区 80%。
- 设置页使用左侧分类导航，右侧页面按卡片分组；插件参数控件继续使用相同全局样式。
- 悬停、按下、焦点、选中和禁用状态由主题统一提供，不在页面中重复定义。
- 自绘组件必须从 `tokens(theme)` 取色；角色专属色只用于头像边框和少量识别标记。
- 任何视觉设置保存都不能清空会话分段计时、改变数据库内容或重启人格。

## 验证清单

改动 UI 后至少检查深浅色、100%/125% Windows 缩放、中文输入法预编辑、短/长气泡、九角色切换、设置页滚动、主题切换阅读位置和分段中的字体保存。原生 Qt 窗口截图用于视觉复查，自动测试用于行为回归。

## 2026-11 生活驾驶舱与共享展示组件

同一个世界，不同房间：工作/资料/日历等功能区强调信息密度和短路径；生活/情感区允许柔和状态色与可替换插画。此次只重排生活页并将关系收进聊天，不重做工作、商城、专注或聊天主布局。

### 组件与布局
- 技术为 **PySide6 Widgets + QSS + QPainter**，不是 PyQt6；没有引入 QML、WebView 或新依赖。
- `module_views/life_widgets.py`：StatusCard、MuscleMap、TrendChart。状态值、上限、标签和进度条分别排版，进度条禁止覆盖文字。状态色取 `design_system.py` 的 RECOVERY_COLORS / STATE_ACCENTS。
- `module_views/life.py`：恢复站、生活上报、运动记录、生活正计时、趋势历史；只调用现有服务。共享表单移到 `module_views/module_forms.py`；旧 `life_work` 导出保留兼容。
- 页面外边距24/20、卡片18/16、卡片间距12/16。正文沿用全局13px与用户选定字体；状态数字32px、计时44px，采用600–650字重。自绘开启抗锯齿，随系统逻辑像素缩放。
- 宽度低于820时主展示与表单两栏上下排列；低于650时状态卡纵排。每个子页单独纵向滚动，不通过拉长窗口容纳内容。图表与人体按比例缩放。
- 不加入持续闪烁或循环动画；静态状态变化即反馈。后续若需要过渡动效，建议120–180ms、OutCubic，不能影响计时精度或数据事件。
- 关系只在聊天标题栏进入，复用原 RelationsPage；同一弹窗复用，不创建第二份关系状态。

### 数据解释
- 状态卡沿用 energy/caps，未填写事实仍使用既有规则估计，不代表测量结果。
- 肌群图覆盖现有六个部位。颜色沿用当前按天恢复规则（当天红、次日橙、第二日黄、第三日起绿）；实际强度、时长、日期在悬停/点击详情显示，不擅自重写医学恢复模型或奖励规则。
- 最近200条记录找不到对应部位时展示灰色“数据不足”，不当作已恢复；未映射的历史部位保留原数据。
- 趋势复用现有近7日重新估计值，并明确不是不可变历史快照。生活上报保存语义、睡眠必填、空值输入、金币结算保持原有实现。

### 美术占位系统
`art_assets.py` 为通用占位与详情组件；外部 `assets/ui/resources.json` 是可修改素材清单，完整英文正负提示词保存于其中，代码含缺失回退。仅在本轮新增的图片位置接入，不强制给满意页面新增装饰。

| 资源 | 尺寸/比例 | 透明 | 构图与路径 |
| --- | --- | --- | --- |
| 人体底图 | 880×660 / 4:3 | 是，PNG | 正面左、背面右；`assets/ui/recovery_body.png` |
| 休息角 | 1200×360 / 10:3 | 否 | 左65%留白，植物/靠枕右侧；`assets/ui/recovery_scene.png` |

在对应区域点击“素材 / 提示词”或“替换与提示词”打开详情，查看用途、尺寸、透明要求、构图和完整路径；Positive / Negative 各有独立复制按钮。放入同名文件后重新打开应用即可。无图片时使用内置示意和柔和占位，不需要下载或生成图片。

人体底图是可选装饰层，必须与440×330逻辑画布上的矢量区域对齐；正面中心约114、背面中心约334，头部y23–66、躯干y80–164。生成图片不能保证精确解剖对齐，替换前应检查构图，必要时继续使用默认示意。程序图层始终负责颜色、命中测试与提示，不能用预染色图替代。

人体底图等比包含显示；休息角等比居中裁切，不拉伸。需要更改裁切焦点时调整素材主体位置，当前不提供复杂美术编辑器。提示词可在清单中修改；新增资源应使用专用的构图与负面约束，不能复用一段通用提示词。

### 窗口边界
`window_geometry.py` 负责按当前屏幕可用区域计算初始尺寸；Windows无边框最大化通过 WM_GETMINMAXINFO 使用当前显示器工作区，保留任务栏，不按整块屏幕覆盖。没有修改聊天布局或移除最大化功能。
