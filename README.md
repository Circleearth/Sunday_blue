# Sunday Blue

Sunday Blue 是个人 Windows 桌面应用。用番茄钟开启工作和学习，用生活记录和每周复盘调整下一步，也可以在雾铃谷把现实中的投入转化为经营进度。日程、笔记、工作和计时可离线使用。聊天和动态评价使用自行配置的模型服务。

## 启动

1. 双击 **SundayBlue.exe** 启动已打包版本，或运行 **Start Sunday Blue Source.cmd** 使用最新源代码。
2. 需要聊天时，在 **设置 → API 连接** 填写协议、请求地址、模型 ID 和密钥。可选 Anthropic Messages 或 OpenAI 兼容 Chat Completions。测试连接会发送一次短请求。
3. 在 **设置 → 外观 / 数据** 可启用关闭到托盘。软件在托盘运行时继续计时和处理到期提醒。在托盘选择 **退出软件** 才会结束主程序和雾铃谷。

模型服务、QQ、滴答清单和 LivingMemory 各自配置。文件访问范围在 **设置 → 角色权限** 指定。运行环境和便携目录见 [Windows 打包与迁移](docs/PACKAGING.md)。

## 入口与常用操作

| 入口 | 用途 |
| --- | --- |
| **此刻** | 看当前状态和下一步。直接接续工作、学习或离屏休息。点击顶栏的当前计划可直达该时段。 |
| **专注** | 选择类别、目标、任务和时长。暂停、结束、长短休息和自动循环共用一个计时入口。 |
| **工作** | 左侧项目树，右侧进度、工时和备注。「任务操作」含暂缓、归档、补报和删除。 |
| **成长** | 知识笔记、复习计划、复习档案、错题档案在「学习」下。限时契约与每周复盘各有入口。 |
| **生活** | 恢复站、生活上报、运动、活动计时和结算报告。生活日以北京时间 04:00 为界，睡眠按完整一晚记录。 |
| **日程** | 日历、提醒、打卡和每周计划。双击计划表可编辑，规范时间段会显示在当前计划。提醒设置管理 QQ 和提示音。 |
| **随手记** | 快速写、改和查找本地笔记。Ctrl+N 新建，Ctrl+S 保存。删除后从回收站恢复，正文继续留在原文件。 |
| **资料** | 选定 Markdown 文件夹后搜索、阅读、编辑和查看修订。阅读时按 Ctrl 并滚动可缩放。 |
| **聊天 / 会议** | 单角色聊天可查历史和创建分支。会议可选角色共同对话，也可单独开启主动交流。 |
| **商店** | 商品、兑换记录和背景素材分区。时间券在右上角，预算奖励从兑换记录确认。 |
| **雾铃谷 ↗** | 顶栏直达游戏。田地、牧场、矿区、工坊、遗迹和集市均可从地图和下方导航进入。 |

日常可以从「此刻 → 专注 → 工作或成长」开始。会议、契约、资料库和滴答同步按需要打开。「此刻 → 更多」管理手机配对和工作日自动静音。

### 雾铃谷入门

初次有 24 谷币、3 块已开农田。点击任一地块可按状态开垦、播种或收获。雾麦有四阶段精灵，成熟后可喂苔羊，也可同时开矿。集市可用工作积分或番茄金币兑换谷币，提交前会显示扣款来源。委托面板显示进度与剩余游戏时间。遗迹可配置队伍和自动续探，工坊可更换装备、试打木桩。

有效专注时现实时间与世界时间等速推进，其余时间按 10:1 推进。关闭游戏窗口可从主程序重新唤醒。引擎文件、存档和美术替换见 [雾铃谷指南](docs/HAMLET.md)。

### 聊天历史和记忆

聊天页显示近期对话，完整原文在「历史记录」按日查阅。Enter 发送，Shift+Enter 换行。可点「压缩」或单独输入 /compact，超过模型安全阈值也会自动压缩。旧消息整理为交接摘要，原始消息留在本地。压缩后可从角色面板点「恢复原文上下文」。如果原文超过模型容量，后续请求仍可再次触发自动压缩。

角色人格、已确认记忆、LivingMemory 和会话原文各自保存。编辑已确认记忆需要审阅。详见 [LivingMemory 与 Ollama](docs/LIVINGMEMORY.md) 和 [角色生命周期](docs/ROLE_SYSTEM_REVIEW.md)。

## 数据与维护

| 位置 | 内容 |
| --- | --- |
| data/conversations.sqlite3 | 会话、原始消息、上下文摘要和工具审计 |
| data/modules.sqlite3 | 工作、计时、生活、日程、复盘、奖励和雾铃谷存档 |
| data/settings.json 和 data/roles.json | 安装和角色设置。API 密钥由当前 Windows 账户保护 |
| personas、assets、extensions | 人格源文件、美术、插件和 Skill |
| data/notebooks | 随手记默认目录。更改目录后，新笔记使用新目录，已有笔记继续引用原路径 |

移动或备份时同时保留 data、personas、assets、extensions，以及自行选定的外部资料与笔记目录。完整便携版还需要主程序、_internal 和 runtime/godot。换 Windows 账户后可能需要重新填写密钥。

- 查某个功能的页面、服务和测试，从 [模块索引](docs/MODULE_INDEX.md) 开始。
- UI 与数据流见 [设计规范](docs/UI_DESIGN_SYSTEM.md)、[架构](docs/ARCHITECTURE.md) 和 [生活与结算](docs/DAILY_EXPERIENCE.md)。
- 新增插件见 [插件规范](handoff/PLUGIN_SPEC.md)。角色辨识特征、立绘验收与英文提示词见 [美术规范](docs/ART_DIRECTION.md)。
- 跨对话继续工作时，以 Git 当前改动、[交接入口](handoff/HANDOFF.md) 和实际测试结果为准。更新交接时写清用户最新决定、涉及文件、验证结果及未验证范围。

## 验证与构建

使用 Windows 原生 Qt 验证交互。局部修改可按相关测试文件运行：

~~~powershell
python -m unittest discover -s tests -p test_module_views.py -v
python -m unittest discover -s tests -p test_hamlet.py -v
~~~

发布前或变更持久化、权限、请求协议、会话生命周期后运行：

~~~powershell
python -m unittest discover -s tests -v
~~~

测试使用隔离数据与本地替身服务。Godot 已安装时，雾铃谷测试会运行真实场景和窗口生命周期。源码验证之后，可双击 **Build Sunday Blue.bat** 重新构建。
