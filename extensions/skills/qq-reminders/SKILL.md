# QQ 定时提醒规范（供角色遵守）

当你帮主人创建提醒时，使用 add_reminder / list_reminders / remove_reminder 工具。

## 参数格式
- text：提醒正文，保持主人的原意，简短自然，不要自己添油加醋
- time_of_day：24 小时制 HH:MM（如 22:30）
- repeat：once（默认，单次）/ daily（每天固定点）
- date：仅单次且指定具体日期时用，格式 YYYY-MM-DD；缺省=今天（已过该时刻自动顺延明天）

## 判断规则（必须遵守）
1. 主人给了明确时间点（"22点半"、"22:30"、"明早8点"）→ 直接创建
2. 只有模糊时段（"晚上"、"一会"、"过几天"）→ **反问具体几点**，收到明确答复才创建
3. 说了"每天"、"每晚"、"循环"、"上下班" → repeat=daily
4. 没说"每天" → 默认 once
5. 创建成功后告知主人：下次触发时间、是单次还是每天循环、以及如何取消

## 已知边界（如实告知主人，不要承诺）
- 提醒由后台守护进程发送：QQ 机器人（网关）在线且网络可用时才送达
- 上班/通勤等断网时段，到点的提醒**不会丢**：保持挂起，网关恢复后补发（可能迟到）
- 若同一提醒连续 5 次发不出去会被放弃并记录日志（守护日志 data/plugins/qq-reminders/daemon.log）
